# NH 주식 모니터

NH투자증권 PLUG Open API로 잔고를 조회해 수익률·몬테카를로 전망·목표 달성 알림을 보여 주는 대시보드. 주문 API는 호출하지 않는다.

## 실행

```bash
DASHBOARD_PASSWORD=비밀번호 uv run stock-monitor   # http://127.0.0.1:7777
```

첫 실행 때 `data/`(권한 700)와 `data/monitor.db`(권한 600)를 만들고, 폴더 안에 `.gitignore`를 넣어 DB가 커밋되지 않게 한다. 앱키·시크릿·텔레그램 설정은 웹 설정 화면에서 입력하며 이 DB에 저장된다. 서버에서는 반드시 HTTPS 리버스 프록시 뒤에 두고 `DASHBOARD_PASSWORD`를 설정한다.

| 환경변수 | 기본값 | |
|---|---|---|
| `DASHBOARD_PASSWORD` | (없음 = 인증 없음) | Basic 인증 비밀번호 |
| `DATA_DIR` | `./data` | DB·토큰 캐시 위치 |
| `HOST` / `PORT` | `127.0.0.1` / `7777` | 바인딩 주소 |
| `REFRESH_MINUTES` | 10 | 잔고 수집 주기 |

## 계산 기준

- 일별 수익률: 하루 마지막 수집 시점의 계좌 총자산(국내 총자산 + 미국 평가금액) 변화에서 그날 외부 입출금(이체·대체 입출금, 현물 대체입고·출고)을 뺀 값. 입금은 장 시작, 출금은 장 마감 기준. 배당·이자·수수료는 수익으로 본다.
- 전체 기간 수익률: 기록 시작 이후 일간 수익률 누적(시간가중). 보유 평가수익률(평가손익/매입금액)도 함께 제공.
- 과거 데이터: 설정 > 과거 기록에서 기간을 정해 버튼을 눌렀을 때만(현재 계정, 또는 이전한 다른 계정의 키를 일회성으로 입력 — 키·토큰은 저장하지 않음) 종합거래내역·해외 일별거래내역으로 날짜별 보유수량·예수금을 만들고 기간별 종가·원/달러 종가로 평가해 빈 날짜를 채운다. 실측 스냅샷은 덮어쓰지 않는 근사치다. 해외주식 과거 시세는 Tiingo 원래 종가(분할 조정 전)만 쓰며 설정 > API 에 Tiingo 키가 필요하다. Tiingo 에 없는 종목을 보유한 날은 건너뛴다.
- 연간 목표(기본 20%): 전년 마지막 스냅샷(없으면 올해 첫 스냅샷) 이후 누적 수익률. 평가수익률 목표(기본 100%): 전체 계좌 합산 평가손익/매입금액. 목표값별로 한 번만 알림.
- 몬테카를로: 계좌 전체 일간 수익률(시간가중, 입출금 제외 — 실제 매매가 반영됨)의 평균·분산으로 GBM. 과거 데이터 구간은 최근 1·3·5년 또는 전체 기간 중 선택(기본 전체 기간).
